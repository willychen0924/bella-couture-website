Bella Couture 白色版 — 本機 HTML 預覽

開啟方法
1. 解壓縮整個資料夾，保留 HTML、CSS、JS 與 assets 的相對位置。
2. 雙擊 index.html，使用 Chrome、Safari 或 Edge 開啟。不需要安裝套件。
3. 如想透過本機伺服器預覽，在此資料夾執行：
   python3 -m http.server 8766 --bind 127.0.0.1
   然後開啟 http://127.0.0.1:8766

頁面
- index.html：品牌首頁（已移除整排預算選購）
- melody.html：系列頁（桌面主圖滿版，高 420px）
- product.html：櫻花商品頁
- story.html：品牌故事（桌面主圖滿版，高 690px）

可操作內容
四頁導覽、手機選單、商品搜尋、分類與預算篩選、價格排序、收藏、圖片切換與放大、數量選擇、模擬購物車、商品說明展開。
其他商品以快速檢視視窗呈現；完整商品頁目前為櫻花項鏈。
收藏和購物車儲存在本機瀏覽器；若瀏覽器限制 file:// 儲存，重新開啟時可能不保留。

此版本透過 GitHub Pages 展示，並可下載到本機瀏覽。沒有訂單、付款、會員或庫存後端。購物車不會送出訂單。
圖片沿用已確認的設計素材，含 AI 輔助珠寶情境與人像背景延伸。正式商品內容和營運資訊仍以品牌確認版本為準。
